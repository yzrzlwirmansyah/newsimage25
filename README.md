One image that sums up 25 November 2026's world news: a 1024×1024 newspaper
front page led by Zelensky's confirmation that Ukraine struck the Russian
cargo ship Sparta II in the Gulf of Finland, with the Houthi strike on
Riyadh's PIF Tower, Huawei's US criminal conviction, the CIA/ODNI breach,
NATO's Poland deployment, and England's T20I win over Australia. Every
story carries its true report date, and every number comes from a checked
source. The image is drawn entirely in code — Python 3.13 standard library
only, no network, no external assets — so the result is fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, under 1 MiB).
